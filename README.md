# canvaaaas

Локальный редактор больших иллюстраций по кускам: выделяете область, пишете промпт, и область перерисовывается через Nano Banana (Gemini image, прокси laozhang.ai). Всё вне выделения остаётся нетронутым.

## Установка

Нужен Node.js 22.18 или новее.

```bash
npm install
```

Ключ laozhang.ai кладётся в Связку ключей macOS (команда спросит ключ, на экран он не выводится):

```bash
security add-generic-password -U -s canvaaaas-laozhang -a api_key -w
```

На Windows (и вообще вместо Связки ключей) ключ можно передать переменной окружения `LAOZHANG_API_KEY`.

## Запуск

```bash
npm start
```

Собирает интерфейс и открывает окно приложения. Внутри работает сервер, который слушает только 127.0.0.1 на свободном порту.

## Как работать

1. «Открыть…» — картинка любого размера (PNG, JPEG, WebP, TIFF) — или пустой холст заданного размера.
2. Выделите область: прямоугольник (R), лассо (L), кисть (B), ластик (E). С Alt прямоугольник и лассо стирают. Рука (H) или зажатый пробел — двигать холст, колесо — масштаб, ⌘0 — вписать, ⌘1 — 100%.
3. Напишите, что сделать с областью, и нажмите «Сгенерировать» (⌘↵). Стиль документа сверху добавляется к каждому запросу.
4. Пока идёт генерация, можно выделять и запускать следующие области: одновременно идут две задачи, остальные ждут.
5. Готовый вариант показывается поверх области. Варианты переключаются стрелками ‹ › (или ← → на клавиатуре).
6. Если модель нарисовала объект крупнее выделения и он обрезан, нажмите «Расширить по правке» или «Править маску» и докрасьте маску кистью. Это перевклейка готового ответа, новой генерации не нужно.
7. «Принять» кладёт правку на холст, «Отклонить» убирает её. В истории любую принятую правку можно выключить и включить обратно; ⌘Z и ⇧⌘Z отменяют и повторяют.
8. «Сохранить PNG» — плоский PNG в полном разрешении.

Каждая генерация платная: счётчик вверху показывает, сколько их было за сеанс и за сегодня, а журнал `generations.jsonl` лежит в папке данных приложения.

## Разработка

```bash
npm run dev
```

Сервер и интерфейс с горячей перезагрузкой на http://127.0.0.1:5173. Переменные окружения: `CANVAAAAS_PROVIDER=mock` — подставная модель вместо платной, `CANVAAAAS_OPEN=путь/к/картинке` — сразу открыть картинку.

```bash
npm run typecheck
```

```bash
npm test
```

## Правка области из командной строки

```bash
npm run edit-region -- --image big.png --mask mask.png --prompt "добавь лодку с красным парусом" --variants 2 --out result.png
```

- `--mask` — PNG того же размера, что и картинка: белое — что менять, чёрное — что оставить.
- `--style` — общий стиль документа, добавляется к каждому запросу.
- `--model flash|pro` — Nano Banana 2 (по умолчанию) или Nano Banana Pro.
- `--size auto|1K|2K|4K` — разрешение ответа модели. `auto` берёт наименьшее, при котором кусок не придётся уменьшать, но не больше 2K. 4K генерируется 4–5 минут, поэтому его нужно указывать явно.
- `--context 0.3`, `--context-min 128` — запас контекста вокруг выделения: доля от размера выделения и минимум в пикселях.
- `--feather 24` — ширина растушёвки внутрь маски, в пикселях.
- `--dry-run` — посчитать кусок и сохранить то, что уйдёт в модель, без генерации.
