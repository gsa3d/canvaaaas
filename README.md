# canvaaaas

Локальный редактор больших иллюстраций по кускам: выделяете область, пишете промпт, и область перерисовывается через Nano Banana (Gemini image, прокси laozhang.ai). Всё вне выделения остаётся нетронутым.

Сейчас готов пайплайн правки области в виде CLI. Интерфейс будет следующим шагом.

## Установка

Нужен Node.js 22.18 или новее.

```bash
npm install
```

Ключ laozhang.ai кладётся в Связку ключей macOS (команда спросит ключ, на экран он не выводится):

```bash
security add-generic-password -U -s canvaaaas-laozhang -a api_key -w
```

На Windows (и вообще вместо Связки ключей) ключ можно передать переменной окружения `LAOZHANG_API_KEY`.

## Правка области

```bash
npm run edit-region -- --image big.png --mask mask.png --prompt "добавь лодку с красным парусом" --variants 2 --out result.png
```

- `--mask` — PNG того же размера, что и картинка: белое — что менять, чёрное — что оставить.
- `--style` — общий стиль документа, добавляется к каждому запросу.
- `--model flash|pro` — Nano Banana 2 (по умолчанию) или Nano Banana Pro.
- `--size auto|1K|2K|4K` — разрешение ответа модели. `auto` берёт наименьшее, при котором кусок не придётся уменьшать (но не больше 4K).
- `--context 0.3`, `--context-min 128` — запас контекста вокруг выделения: доля от размера выделения и минимум в пикселях.
- `--feather 24` — ширина растушёвки внутрь маски, в пикселях.
- `--dry-run` — посчитать кусок и сохранить то, что уйдёт в модель, без генерации.

Каждая генерация платная и записывается в журнал `generations.jsonl` в папке данных приложения.
