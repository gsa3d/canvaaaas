# canvaaaas

[English version](README.md)

Редактор больших иллюстраций по кускам. Выделяете область, пишете, что там должно быть, и генеративная модель перерисовывает только её. Всё вне выделения остаётся побайтно прежним.

- **Большие картинки.** 8000×6000 и больше: холст тайлами, вся работа с пикселями — в приложении, а не в canvas браузера.
- **Точные правки.** Модель видит кусок вокруг выделения, её ответ вклеивается обратно по вашей маске с мягким краем. Модели не принимают маски, но меняется всё равно только выделенное.
- **Две модели картинок.** Nano Banana 2 и Nano Banana Pro (Gemini image) по ключу [laozhang.ai](https://laozhang.ai) или ChatGPT Images по подписке ChatGPT через Codex — без ключа.
- **Слои и версии.** Каждый ответ — версия слоя: их можно переключать, сравнивать, скрывать, группировать, объединять, править маску слоя кистью.
- **Выделение объектов.** «Палочка» выделяет объекты моделью SAM 2.1, которая работает прямо на компьютере.
- **Директор и критик.** По желанию ChatGPT сначала расписывает задачу по вашим словам и картинке, а правка идёт шагами: после каждого критик говорит, что исправить.
- **Набросок и референсы.** Набросок показывает, где и каким должно быть то, что в задаче; до трёх референсов на правку; общий стиль документа.

Интерфейс — на английском или на русском, если система по-русски (переключается в настройках).

### macOS

1. Откройте `.dmg` и перетащите **canvaaaas** в **Программы**.
2. Приложение не заверено Apple, поэтому при первом запуске macOS его не откроет. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть** рядом с canvaaaas — или один раз выполните в Терминале:

   ```bash
   xattr -dr com.apple.quarantine /Applications/canvaaaas.app
   ```

### Windows

Запустите установщик. Он ставит canvaaaas только для вашего пользователя, права администратора не нужны. Установщик не подписан, поэтому SmartScreen может написать «Система Windows защитила ваш компьютер»: нажмите **Подробнее → Выполнить в любом случае**.

## Настройка

canvaaaas нужна хотя бы одна модель картинок. Откройте **Настройки** (⌘, на macOS, Ctrl+, на Windows).

**Nano Banana 2 и Nano Banana Pro.** Создайте ключ API на [laozhang.ai](https://laozhang.ai) и вставьте его в настройки. Ключ хранится в Связке ключей macOS или, на Windows, зашифрованным для вашей учётной записи; уходит он только в laozhang.ai. Каждую генерацию оплачиваете в laozhang.ai.

**ChatGPT Images.** Ключ не нужен: картинки рисует Codex, вошедший в ваш аккаунт ChatGPT, и генерации идут в счёт лимитов подписки. Установите [приложение ChatGPT](https://chatgpt.com/download) (в нём есть Codex) или [Codex CLI](https://github.com/openai/codex) и войдите (`codex login`). Где canvaaaas нашёл Codex — видно в настройках. Директор и критик тоже работают через Codex.

**Выделение объектов.** При первом щелчке «Палочкой» canvaaaas предложит скачать модель SAM 2.1 (272 МБ, один раз). Она работает на компьютере, без интернета и бесплатно.

## Как работать

1. **Откройте** картинку (⌘O): PNG, JPEG, WebP, TIFF или проект canvaaaas (`.caaa`). Или создайте **новый холст** (⌘N).
2. **Выделите**, что поменять: «Палочка» (W) берёт объект под щелчком, ещё есть прямоугольник (R), лассо (L) и кисть (B). Shift добавляет к выделению, Alt вычитает. Пунктирная рамка — кусок, который увидит модель.
3. **Опишите результат** в поле правки — что должно быть, а не что исправить. По желанию — **набросок** (S), **референсы** (перетащить, вставить или выбрать до трёх картинок) и **стиль** документа.
4. Выберите модель, разрешение и число вариантов и нажмите **«Сгенерировать»** (⌘↵). На кнопке написано, куда ляжет результат и сколько это генераций.
5. Каждый ответ — **версия** слоя. Версии переключаются в ленте под холстом (← →), наведение показывает версию на холсте, F — к куску.
6. Края: щелчок по миниатюре маски рядом со слоем — кисть скрывает или возвращает части, **«Маска → По правке»** добавляет к маске то, что модель нарисовала за краем выделения. **«Поправить задачу»** и **«Ещё»** дают новые версии того же слоя.
7. **Сохраните** (⌘S). В проекте `.caaa` остаются все слои и версии. В картинку видимое сливается; **«Экспортировать картинку»** (⇧⌘E) пишет копию, а документ остаётся проектом.

Ещё в поле правки:

- **«Директор»** — ChatGPT сначала расписывает задачу, а правка идёт шагами с критиком, пока он не скажет «готово».
- **«Маска по объекту»** — модель рисует каждой версии ещё и маску нового объекта, и слой становится ровно этим объектом.
- **«С нуля»** — модель получает выделенную область залитой серым и рисует её заново, не держась за то, что там было.

Клавиши: ⌘Z и ⇧⌘Z — отменить и повторить, ⌘D — снять выделение, ⌘J — слой из выделения, ⇧⌘J — вырезать в слой, ⌘G — сгруппировать, ⌘E — объединить, H или пробел — двигать холст, ⌘0 — вписать в окно, ⌘1 — 100%, зажатый `\` — исходник картинки.

### Как писать промпт

- Описывайте результат, а не проблему: не «исправь нестыковку рельсов», а «рельсы на мосту продолжают колею слева, без разрыва, с теми же шпалами».
- Выделяйте только то место, которое надо поменять, с небольшим запасом. Если кусок намного больше ответа модели, он теряет детализацию — об этом предупреждает подсказка о разрешении.
- Для правок, где модели надо «подумать» (перспектива, согласование деталей), попробуйте Nano Banana Pro: она медленнее и дороже, но рассуждает лучше.

### Сохранение

Холст внутри canvaaaas — sRGB, 8 бит, без прозрачности. Если исходный файл другой — есть прозрачность, 16 бит на канал, профиль Display P3 или Adobe RGB, CMYK или это TIFF, где могут быть слои Photoshop, — «Сохранить» его не перезапишет и спросит новое имя. PNG и WebP перезаписываются без потерь; JPEG при каждом сохранении пережимается заново (качество 95), поэтому для долгой работы держите копию в PNG или `.caaa`.

## Приватность и деньги

- canvaaaas работает на вашем компьютере, его встроенный сервер слушает только 127.0.0.1.
- Модели уходит только кусок вокруг выделения (с наброском и референсами): в laozhang.ai для Nano Banana, в OpenAI через Codex для ChatGPT Images.
- Каждая генерация стоит денег или лимита подписки. Счётчик вверху показывает генерации за сеанс и за сегодня, а все вызовы пишутся в `generations.jsonl` в папке данных приложения (`~/Library/Application Support/canvaaaas` на macOS, `%APPDATA%\canvaaaas` на Windows).

## Сборка из исходников

Нужен [Node.js](https://nodejs.org) 22.18 или новее.

```bash
npm install
```

```bash
npm start
```

`npm start` собирает приложение и открывает его в Electron. Установщики — `npm run dist:mac` (на Mac с Apple Silicon) и `npm run dist:win` (на Windows или на Mac: там он собирается в копии проекта с Windows-версиями зависимостей в `work/win-build`). `npm run install:mac` собирает приложение и кладёт его в «Программы».

Разработка в браузере, с подставной моделью, которая ничего не стоит:

```bash
CANVAAAAS_PROVIDER=mock npm run dev
```

Дальше — http://127.0.0.1:5173. `CANVAAAAS_LANG=en` или `ru` — язык вместо системного, `CANVAAAAS_OPEN=путь/к/картинке.png` — сразу открыть картинку.

```bash
npm run typecheck
```

```bash
npm test
```

### Командная строка

```bash
npm run edit-region -- --image big.png --mask mask.png --prompt "добавь лодку с красным парусом" --variants 2 --out result.png
```

Маска — PNG того же размера: белое — что перерисовать, чёрное — что оставить. Без аргументов команда покажет все параметры.
