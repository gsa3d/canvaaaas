# canvaaaas

Локальное приложение для правки больших иллюстраций по кускам: выделяю область, пишу промпт, область перерисовывается генеративной моделью и вклеивается обратно. Общение и интерфейс — на русском.

## Стек
- TypeScript (strict), Node ≥ 22.18: `.ts` запускается напрямую через встроенное в Node удаление типов, без сборки. Поэтому в коде только «стираемый» синтаксис (`erasableSyntaxOnly`): без enum, namespace и параметров-свойств в конструкторах. Импорты пишутся с расширением `.ts`.
- sharp (libvips) — все пиксельные операции. Позже Electron + Vite для UI, сборка под macOS и Windows.
- Проверки: `npm run typecheck`, `npm test` (vitest).

## Ограничения, которые нельзя нарушать
- Генерация сейчас — Nano Banana (Gemini image) через прокси laozhang.ai, формат Google `generateContent`, ключ в `Authorization: Bearer`. Ключ берётся из `LAOZHANG_API_KEY` или из Связки ключей macOS (сервис `canvaaaas-laozhang`, аккаунт `api_key`). Ключ никогда не выводится в лог, консоль, ошибки или чат и не кладётся в папку проекта (она синхронизируется в Dropbox).
- Каждая генерация стоит денег. Без явного согласия пользователя — не больше ~10 генераций за тестовый прогон. Все вызовы пишутся в журнал (`src/core/ledger.ts`).
- Модель не принимает маски. Маску делаем сами: вырезаем кусок с контекстом, генерируем, вклеиваем по маске с растушёвкой внутрь маски. Пиксели, где маска = 0, остаются побайтно равными оригиналу — это проверяет автотест.
- Картинки большие (8000×6000 и больше): пиксельная работа только на бэкенде, не в браузерном canvas.
- Сервер (когда появится) слушает только 127.0.0.1.
- `node_modules/` и `work/` исключены из синхронизации Dropbox атрибутом `com.apple.fileprovider.ignore#P`.

## Устройство
- `src/providers/` — провайдеры генерации за общим интерфейсом `ImageProvider` (`types.ts`): `laozhang-gemini.ts` (Nano Banana 2 и Pro), `mock.ts` для тестов.
- `src/core/` — пайплайн правки области: `frame.ts` (рамка куска и пропорции модели), `mask.ts` (bbox, растушёвка, подсветка), `edit-region.ts` (весь цикл), `ledger.ts` (журнал генераций).
- `src/cli/edit-region.ts` — CLI шага 1. `scripts/recon.ts` — разведка шага 0.
