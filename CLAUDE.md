# canvaaaas

Локальное приложение для правки больших иллюстраций по кускам: выделяю область, пишу промпт, область перерисовывается генеративной моделью и вклеивается обратно. Общение и интерфейс — на русском.

## Стек
- TypeScript (strict), Node ≥ 22.18. Сервер, ядро и скрипты — `.ts`, который Node запускает напрямую (встроенное удаление типов), поэтому там только «стираемый» синтаксис (`erasableSyntaxOnly`): без enum, namespace и параметров-свойств. Импорты — с расширением `.ts`.
- sharp (libvips) — все пиксельные операции. Интерфейс — Preact + OpenSeadragon (тайлы), собирается Vite. Оболочка — Electron; её main собирается esbuild в `dist/electron/main.mjs`.
- Запуск: `npm start` (сборка + окно Electron), `npm run dev` (сервер + Vite на http://127.0.0.1:5173; `CANVAAAAS_PROVIDER=mock` — без платных генераций, `CANVAAAAS_OPEN=путь` — сразу открыть картинку). Для встроенного браузера есть `.claude/launch.json` (`canvaaaas-mock`, `canvaaaas-real`).
- Проверки: `npm run typecheck` (корень и `src/renderer`), `npm test` (vitest, `test/`). Проверка сборки Electron: `npm run build && npx electron . --smoke`.

## Ограничения, которые нельзя нарушать
- Генерация сейчас — Nano Banana (Gemini image) через прокси laozhang.ai, формат Google `generateContent`, ключ в `Authorization: Bearer`. Ключ берётся из `LAOZHANG_API_KEY` или из Связки ключей macOS (сервис `canvaaaas-laozhang`, аккаунт `api_key`). Ключ никогда не выводится в лог, консоль, ошибки или чат и не кладётся в папку проекта (она синхронизируется в Dropbox).
- Каждая генерация стоит денег. Без явного согласия пользователя — не больше ~10 генераций за тестовый прогон. Все вызовы пишутся в журнал (`src/core/ledger.ts`).
- Модель не принимает маски. Маску делаем сами: вырезаем кусок с контекстом, генерируем, вклеиваем по маске с растушёвкой внутрь маски. Пиксели, где маска = 0, остаются побайтно равными оригиналу — это проверяет автотест.
- Картинки большие (8000×6000 и больше): пиксельная работа только на бэкенде, не в браузерном canvas.
- Сервер слушает только 127.0.0.1, изменяющие запросы — только с заголовком `x-canvaaaas`.
- `node_modules/` и `work/` исключены из синхронизации Dropbox атрибутом `com.apple.fileprovider.ignore#P`.

## Устройство
- `src/providers/` — провайдеры генерации за общим интерфейсом `ImageProvider` (`types.ts`): `laozhang-gemini.ts` (Nano Banana 2 и Pro, undici с таймаутом 10 минут), `mock.ts` для тестов и разработки.
- `src/core/` — пиксельное ядро: `frame.ts` (рамка куска и пропорции модели), `mask.ts` (bbox, растушёвка, подсветка), `mask-shapes.ts` (фигуры выделения → маска), `expand.ts` (расширение маски по правке), `edit-region.ts` (подготовка куска, слой правки, вклейка), `document.ts` (исходник + слои правок, пирамида тайлов, undo/redo), `ledger.ts` (журнал генераций), `secrets.ts` (ключ).
- `src/server/` — `session.ts` (документ и очередь задач: не больше 2 одновременно; ответы моделей хранятся, поэтому смена маски — бесплатная перевклейка), `app.ts` (HTTP на 127.0.0.1: проверка Host и заголовок `x-canvaaaas` у изменяющих запросов), `main.ts` (сервер без Electron).
- `src/shared/api.ts` — типы API, общие для сервера и интерфейса. `src/renderer/` — интерфейс: `viewer.ts` (OpenSeadragon + оверлей выделения), `App.tsx`. `src/electron/main.ts` — окно.
- `src/cli/edit-region.ts` — CLI правки области. `scripts/recon.ts` — разведка шага 0, итоги в `docs/recon.md`.
